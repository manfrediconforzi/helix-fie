## Scientific contract

Historical Maximum and Robust Maximum are separate.
Reliability is always paired with Coverage.
NO EDGE and INSUFFICIENT EVIDENCE are valid outputs.

Three prediction targets remain separate:
1. direction;
2. benchmark outperformance;
3. economically attractive return.

Horizons are independent prediction problems:
24H / 30D / 90D / 120D / 150D / 1Y.

No state may be rendered healthy or green without verifiable evidence.
RUNNING never implies SCIENTIFICALLY_VALIDATED.

## ZERO LOSS contract

No recovered legacy capability is silently removed.
Every capability must remain in the registry and receive one explicit disposition:
RETAIN / ADAPT / REBUILD / DEPRECATE / QUARANTINE.

UI simplification may hide complexity from a surface but may not erase capability, lineage, failed experiments or negative knowledge.

## Infrastructure

Layerbase `helix-prod` is the canonical database target.
Legacy Supabase remains archaeological/runtime legacy until every required dependency is replaced and independently verified.
No dual-write and no automatic bulk import of legacy data.
