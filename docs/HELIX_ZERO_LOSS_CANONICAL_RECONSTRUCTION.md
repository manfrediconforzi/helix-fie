## 0. Purpose

This document restores the intended HELIX architecture before the implementation drift that mixed scientific runtime, database migration, UI reconstruction and new feature work.

ZERO LOSS means:
- no legacy capability is silently deleted;
- no new UI is allowed to imply that an unconnected capability is running;
- no scientific result is promoted by presentation quality;
- no database migration is allowed to redefine the scientific architecture;
- every recovered capability receives an explicit disposition: RETAIN, ADAPT, REBUILD, DEPRECATE or QUARANTINE;
- DEPRECATE does not mean erase: evidence, lineage, negative knowledge and rationale remain preserved;
- VORTEX is the master truth layer, HELIX is the scientific machine, FIE is the decision-facing product.
